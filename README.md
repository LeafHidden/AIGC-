# 🎬 AIGC AI短剧全流程指令

一套用于 **AI短剧 / AI漫剧制作** 的完整指令工作流。

通过不同指令分别完成：

```text
小说创作
↓
小说改编剧本
↓
角色资产
↓
场景 / 道具资产
↓
分镜 / 视频提示词
↓
AI视频生成
```

目标是让 AI 从单纯“生成内容”，变成一套相对完整的 **AI短剧生产流程**。

---

## 📦 指令列表

### 1. AIGC小说

用于创作原创小说。

支持：

* 随机生成故事
* 根据用户想法创作
* 悬疑、科幻、奇幻、现实、惊悚等题材
* 微型、短篇、中篇、长篇

重点保证：

**故事完整、人物驱动、逻辑合理，并尽量适合后续影视化。**

---

### 2. AIGC小说转剧本

将小说、故事梗概或已有剧情改编成适合 AI 漫剧制作的剧本。

主要完成：

* 小说剧情影视化
* 心理描写转为动作和画面
* 分集
* 场次
* 对白
* 开场钩子
* 剧情转折
* 集尾卡点

最终得到可以继续进入角色、场景和分镜制作的剧本。

---

### 3. AIGC漫剧角色资产师

根据剧本提取和设计角色资产。

包括：

* 角色外貌
* 年龄、体型、脸型
* 发型、服装
* 身份特征
* 角色强锚点
* 三视图提示词
* 表情、动作提示词

主要用于提高同一个角色在不同镜头中的一致性。

---

### 4. AIGC漫剧场景道具师

根据剧本建立场景和关键道具资产。

包括：

* 场景结构
* 门窗、出入口
* 永久锚点
* 灯光和天气
* 常用机位
* 道具尺寸、材质、结构和状态

主要解决 AI 漫剧中的：

**背景漂移、空间变化、道具变形和位置错乱。**

---

### 5. sd2.0视频提示词焚诀

将：

* 剧本
* 剧情
* 单镜头
* 已有分镜
* 参考图片

转换成可以直接用于 **Seedance 2.0** 的视频提示词。

支持：

```text
T2V
I2V
R2V
Extend
Edit
```

自动规划：

* 镜头
* 运镜
* 人物动作
* 微表情
* 时间轴
* 声音
* 环境变化
* 物理反馈
* 首尾帧连续性

单个生成段默认控制在 15 秒以内。

---

### 6. AIGC漫剧动态镜头导演

可选增强指令。

主要用于已经确定分镜之后，将静态镜头进一步转换成：

* 人物动作
* 动作时间轴
* 运镜
* 表演
* 微表情
* 物理反馈
* 环境动态
* 镜头衔接

适合对动作和镜头质量要求更高的项目。

---

# 🚀 使用方法

使用方式非常简单。

将对应的 `.md` 指令添加给 AI 模型，然后直接提出需求。

例如：

```text
【添加】

AIGC小说.md

【提问】

随机生成一个适合AI短剧改编的悬疑短篇故事。
```

或者：

```text
【添加】

AIGC漫剧角色资产师.md

【提问】

根据下面的剧本提取所有主要角色，
并生成对应的角色提示词。
```

不同阶段切换对应指令即可。

# 📖 示例

例如你只有一个想法：

```text
一个男人发现，
每天晚上睡着以后，
都会被另一个世界的自己替换。
```

首先使用：

```text
AIGC小说
```

生成完整故事。

然后使用：

```text
AIGC小说转剧本
```

将小说改编成短剧剧本。

再分别使用：

```text
AIGC漫剧角色资产师
AIGC漫剧场景道具师
```

建立人物、场景和道具资产。

最后使用：

```text
sd2.0视频提示词焚诀
```

将剧本镜头转换为 Seedance 2.0 视频提示词，即可进入 AI 视频生成阶段。

---

# 💡 推荐原则

不要使用一个超长 Prompt 同时处理：

```text
小说 + 剧本 + 角色 + 场景 + 分镜 + 视频
```

推荐按照不同阶段分别使用对应指令。

这样更容易保证：

* 剧情稳定
* 角色一致
* 场景一致
* 镜头连续
* 视频提示词清晰

---

# 🎬 总结

整套流程可以简单理解为：

```text
想法
→ 小说
→ 剧本
→ 角色
→ 场景
→ 分镜
→ 视频提示词
→ AI视频
```

通过不同 AI 指令承担不同岗位，让 AI 协助完成从 **故事创作到最终视频生成** 的完整工作流。
